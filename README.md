# Lapak Kita / Laravel Application

A modern full-stack web application built with the Laravel ecosystem, featuring Livewire, Filament Admin Panel, Spatie Permissions, Activity Logging, and Midtrans Payment Gateway integration.

---

## 🛠️ Tech Stack & Dependencies

- **PHP**: `^8.3`
- **Framework**: Laravel `^13.17`
- **Frontend / UI**: Livewire `^4.3`, Tailwind CSS, Vite
- **Admin Panel**: Filament `~5.0`
- **Authentication**: Laravel Breeze
- **Permissions & Security**: Spatie Laravel Permission
- **Audit Trail**: Spatie Activity Log
- **Payment Gateway**: Midtrans PHP SDK
- **Testing**: Pest PHP
- **Code Quality & Utilities**: Laravel Pint, Pail, Boost

---

## 🚀 Requirement

Sebelum memulai, pastikan sistem kamu sudah terinstal:
- PHP >= 8.3
- Composer >= 2.x
- Node.js & NPM
- MySQL / SQLite Database

---

## ⚡ Quick Setup (Cara Install)

Kamu bisa menggunakan script bawaan Composer untuk melakukan instalasi otomatis secara cepat:

```bash
# 1. Clone repository
git clone [https://github.com/donyyulihandoko/nama-repo.git](https://github.com/donyyulihandoko/nama-repo.git)
cd nama-repo

# 2. Jalankan perintah automated setup
composer run setup
